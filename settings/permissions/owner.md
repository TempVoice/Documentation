# Temporary Channel Owner Permissions

> **Where do I find this?**
>
> Open the [Dashboard](https://tempvoice.xyz/dashboard) -> Select your Discord server -> Select the **correct** Creator Channel -> Click on the `Permissions` tab -> `Temporary Channel Owner Permissions`

<figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>

You can grant these permissions:

* **Manage:** Manage Permissions, Manage Channels, Delete Messages and Disconnect Members.
* **Text:** Create Invite, Send Polls, Send Voice Messages, Use External Emoji, Use External Stickers and Use External Sounds.
* **Voice:** Webcam and Screenshare, Priority Speaker, Use Voice Activity, Set Voice Channel Status, Use Soundboard and Use Activities.

{% hint style="danger" icon="gear-complex" %}
Giving channel owners **Manage Permissions** is not recommended. Owners can easily break TempVoice by editing the wrong permissions.
{% endhint %}

{% hint style="info" %}
Granting **Disconnect Members** (Discord's **Move Members** permission) also lets owners [kick moderators](../../commands/voice/user/kick.md#immune) out of their temporary channel.
{% endhint %}
