# TempVoice Appearance

> **Where do I find this?**
>
> Open the [Dashboard](https://tempvoice.xyz/dashboard) -> Select your Discord server -> `TempVoice Appearance`

{% hint style="info" icon="crown" %}
TempVoice Appearance requires [TempVoice Premium](https://tempvoice.xyz/premium).
{% endhint %}

Click on the avatar or banner to upload a new image, and click on the name or bio to edit them. Use `Save Changes` to apply your changes.

| Setting  | Limits                                                                                       |
| -------- | -------------------------------------------------------------------------------------------- |
| Avatar   | PNG, JPEG, GIF or WebP, smaller than 8 MB                                                    |
| Banner   | PNG, JPEG, GIF or WebP, smaller than 8 MB. You can position and zoom every format except GIF |
| Nickname | Up to 32 characters                                                                          |
| Bio      | Up to 190 characters                                                                         |

These changes only apply to your Discord server. Remove a server avatar or banner to go back to the default of the bot.

{% hint style="warning" %}
The bot needs the **Change Nickname** permission on your server to save these changes.
{% endhint %}

Using [Your Own Instance](../../help/premium.md#your-own-instance)? The global profile of your bot is managed on the [Premium page](https://tempvoice.xyz/premium) instead.
