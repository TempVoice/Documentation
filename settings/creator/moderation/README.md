# Moderation

> **Where do I find this?**
>
> Open the [Dashboard](https://tempvoice.xyz/dashboard) -> Select your Discord server -> Select the **correct** Creator Channel -> Click on the `Moderation` tab

| Setting                                                 | What it does                                                     |
| ------------------------------------------------------- | ---------------------------------------------------------------- |
| [Toggle Features](features.md)                          | Choose which features channel owners can use                     |
| [Moderation Log](log.md)                                | Log temporary channel actions to a text channel with a webhook   |
| [Recover Owner Settings](restore.md)                    | Recover a channel with the settings it had before it was deleted |
| [Censor Channel Names](censor.md)                       | Censor inappropriate words in temporary channel names            |
| [Age Restriction for In-Voice Chat](age_restriction.md) | Make users confirm their age to see the in-voice chat            |
| [Vote Kick Percentage](vote-kick-percentage.md)         | Set how many voters have to agree before a user is kicked        |
