# Overview

> **Where do I find this?**
>
> Open the [Dashboard](https://tempvoice.xyz/dashboard) -> Select your Discord server -> Select the **correct** Creator Channel -> Click on the `Overview` tab

| Setting                                   | What it does                                                     |
| ----------------------------------------- | ---------------------------------------------------------------- |
| [Temporary Channel Name](name.md)         | Set the default name format and the waiting room name            |
| [Temporary Channel User Limit](limit.md)  | Set the default user limit and the range owners can choose from  |
| [Temporary Channel Category](category.md) | Choose the category for new channels and its fallback categories |
| [Temporary Channel Bitrate](bitrate.md)   | Choose the audio bitrate, limited by your server's boost level   |
| [Temporary Channel Position](position.md) | Set where new channels appear in relation to the Creator Channel |
