# Creator Settings

Open the [Dashboard](https://tempvoice.xyz/dashboard), select your Discord server and select a [Creator Channel](../server/creators.md). Its settings are split into four tabs:

| Tab                           | What you can change                                                                                 |
| ----------------------------- | --------------------------------------------------------------------------------------------------- |
| [Overview](overview/)         | Name, user limit, category, bitrate and position of temporary channels                              |
| [Permissions](permissions/)   | Access roles, channel permissions, privacy mode and owner permissions                               |
| [Moderation](moderation/)     | Toggle features, moderation log, recovering owner settings, censoring names, age restriction and vote kicks |
| [Others](others/)             | Greeting, interface for the in-voice chat and voice role                                            |
