# Others

> **Where do I find this?**
>
> Open the [Dashboard](https://tempvoice.xyz/dashboard) -> Select your Discord server -> Select the **correct** Creator Channel -> Click on the `Others` tab

| Setting                                               | What it does                                                      |
| ----------------------------------------------------- | ----------------------------------------------------------------- |
| [Temporary Channel Greeting](greeting.md)             | Send a message to the in-voice chat when a channel is created     |
| [TempVoice Interface for In-Voice Chat](interface.md) | Send the interface to the in-voice chat when a channel is created |
| [Temporary Voice Role](voice-role.md)                 | Give users a role while they are in a temporary channel           |
