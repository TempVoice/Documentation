# Permissions

> **Where do I find this?**
>
> Open the [Dashboard](https://tempvoice.xyz/dashboard) -> Select your Discord server -> Select the **correct** Creator Channel -> Click on the `Permissions` tab

| Setting                                           | What it does                                                   |
| ------------------------------------------------- | -------------------------------------------------------------- |
| [Temporary Channel Access Roles](access-roles.md) | Select the roles required to see or join temporary channels    |
| [Temporary Channel Permissions](sync.md)          | Choose where temporary channels get their permissions from     |
| [Temporary Channel Privacy Mode](privacy.md)      | Choose if new channels are public, locked or hidden by default |
| [Temporary Channel Owner Permissions](owner.md)   | Give owners extra permissions while they control a channel     |
