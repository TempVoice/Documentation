# Quickstart

## Invite TempVoice™

Visit [https://tempvoice.xyz/invite](https://tempvoice.xyz/invite) to invite <img src="../.gitbook/assets/image (25) (1) (1).png" alt="" data-size="line"> to your Discord server

## Initial Setup

## ➕ Creator Channel

A voice channel that creates a temporary channel when you join it. To set up more Creators, use `/setup` -> `New Creator` or add them in the [Dashboard](../settings/server/creators.md). Each Creator has its own configuration for creating temporary channels.

{% hint style="info" icon="gear-complex" %}
You can have multiple ➕ **Creator Channels**, each of which can be configured individually in the [Dashboard](https://tempvoice.xyz/dashboard) to create temporary channels in different ways. The Free plan includes 2 Creator Channels. [TempVoice Premium](https://tempvoice.xyz/premium) unlocks unlimited Creator Channels.
{% endhint %}

## ✨ Interface Message

A text channel in which the bot sends an [interface](../commands/interface-message.md). Its buttons are an alternative to the [/voice](../commands/voice/) commands for customizing a temporary channel.

{% hint style="info" icon="gear-complex" %}
You can have unlimited ✨ **Interface Messages**. Send one to the channel you are in with `/setup` -> `New Interface`, or [customize it and send it from the Dashboard](../settings/server/interface.md). You can also send it directly to the chat of every temporary channel with [TempVoice Interface for In-Voice Chat](../settings/creator/others/interface.md).
{% endhint %}
