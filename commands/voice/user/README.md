# user

Use `/voice user` followed by one of these subcommands:

| Command               | What it does                                                    |
| --------------------- | --------------------------------------------------------------- |
| [trust](trust.md)     | Give a user access, even while your channel is locked or hidden |
| [untrust](untrust.md) | Remove a user from your trusted list                            |
| [block](block.md)     | Kick a user and stop them from joining again                    |
| [unblock](unblock.md) | Remove a user from your block list                              |
| [kick](kick.md)       | Disconnect users and revoke their access, or start a vote       |
| [invite](invite.md)   | Invite a user directly by DM                                    |
