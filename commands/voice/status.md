---
description: >-
  Set a short status text that Discord shows below your temporary channel in
  the channel list, for example what you are playing or talking about.
---

# status

```
/voice status input:Ranked grind, join if you're Gold+
```

* The status can be up to **500 characters** long.
* Leave `input` blank to remove the status.
* Words blocked by [Censor Channel Names](../../settings/moderation/censor.md) are censored in the status too.
* If your channel is hidden, the confirmation is only visible to you.

{% hint style="info" %}
This command is available for 12 hours after voting on [Top.gg](https://top.gg/bot/762217899355013120/vote). After that, you'll need to vote again. With [TempVoice Premium](https://tempvoice.xyz/premium), you don't need to vote at all.
{% endhint %}

{% hint style="success" icon="gear-complex" %}
Server admins can disable this command or limit it to certain roles with the **Changing Channel Status** feature in [Toggle Features](../../settings/moderation/features.md).
{% endhint %}
