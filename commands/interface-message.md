* The `BITRATE`, `INFO` and `RESET` buttons are off by default. Server admins can turn them on, turn off other buttons and change the order in [Customize and Send the Interface](../settings/server/interface.md).
* `DELETE` and `RESET` ask you to confirm first.
* To send the interface automatically to each new channel instead, see [TempVoice Interface for In-Voice Chat](../settings/creator/others/interface.md).
* Each button follows the same rules as its command, including [voting](voice/#commands).
