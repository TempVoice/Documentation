# Apps Commands

Right-click a user (or long-press on mobile), open **Apps** and choose one of the TempVoice commands. You have to be the owner of the temporary channel you are connected to. Moderators can also use **Transfer Ownership** on channels they don't own.

| Command                | Equivalent Chat Command                                   | Requires vote |
| ---------------------- | --------------------------------------------------------- | :-----------: |
| **Disconnect**         | Disconnects the user from your channel                    |               |
| **Send Invite**        | [/voice user invite](voice/user/invite.md)                |       ✓       |
| **Transfer Ownership** | [/voice transfer](voice/transfer.md)                      |       ✓       |

**Disconnect** only works while your channel is locked, hidden or has a user limit, and it skips moderators like an [instant kick](voice/user/kick.md#instant). Unlike an instant kick, it only disconnects the user: they stay on your trusted list and keep any access they have.

See [Why some users get ignored/skipped?](../faq/skipped.md) for the reasons a user can be skipped.

{% hint style="info" %}
Commands marked with ✓ are available for 12 hours after voting on [Top.gg](https://top.gg/bot/762217899355013120/vote). After that, you'll need to vote again. With [TempVoice Premium](https://tempvoice.xyz/premium), you don't need to vote at all.
{% endhint %}
