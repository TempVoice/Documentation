# /setup

You need the **Manage Server** permission to use this command.

| Button            | What it does                                                                                                                       |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `Setup TempVoice` | Creates a `TEMPVOICE CATEGORY` with a `➕ Creator Channel` and a `✨・interface` channel                                             |
| `New Creator`     | Creates another category with a [Creator Channel](../settings/server/creators.md)                                                   |
| `New Interface`   | Sends an [interface](interface-message.md) to the channel you are in                                                               |

`New Creator` and `New Interface` are available after your server has its first Creator Channel.

{% hint style="info" icon="crown" %}
The Free plan includes 2 Creator Channels. [TempVoice Premium](https://tempvoice.xyz/premium) unlocks unlimited Creator Channels.
{% endhint %}

Continue with the [Quickstart](../getting-started/setup.md), or customize your Creator Channels in the [Dashboard](https://tempvoice.xyz/dashboard).
