# How to change the language for TempVoice?

[Dashboard](https://tempvoice.xyz/dashboard) -> Select your Discord server -> TempVoice Language

You can choose English, German, Dutch, French, Spanish, Portuguese, Italian, Greek, Turkish, Russian, Ukrainian, Polish, Vietnamese, Indonesian, Korean, Japanese and Arabic.
