# {NUMBER\_ROMAN}

## Example

```
🦊・{NUMBER_ROMAN} Voice Channel
```

How multiple temporary channels from a creator could look like:

```
🦊・I Voice Channel
🦊・II Voice Channel
🦊・III Voice Channel
🦊・IV Voice Channel
🦊・V Voice Channel
```

{% hint style="info" %}
The number is the lowest one not used by another temporary channel of the same Creator Channel. If channel 2 is deleted, the next new channel gets number 2 again, so the numbers don't always appear in order.
{% endhint %}
