# {OWNER\_ID}

## Example

```
Owner ID: {OWNER_ID}
```

If the user ID of the channel owner is 123456789012345678:

```
Owner ID: 123456789012345678
```

{% hint style="info" %}
Only available in the [Temporary Channel Greeting](../../settings/others/greeting.md).
{% endhint %}
