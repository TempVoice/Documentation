description: Replaced by the nickname of the temporary channel owner.
---

# {OWNER\_NICKNAME}

## Example

```
🐶・{OWNER_NICKNAME}
```

If the owner's nickname on the server is **Jonah** or **Juu**:

```
🐶・Jonah
```

```
🐶・Juu
```

If the owner has no nickname on the server, their display name is used.
